## 项目背景

Udify 是意图驱动的自动化内容魔改平台，首攻游戏 Mod（RPG Maker/Unity/Godot/miu2d）。
当前状态：Python 399 测试全绿，Next.js 15 审阅工作台已上线，引擎闭环本地真实成立。
迭代方向：infra 扎实化 + 前端可配置性增强。
