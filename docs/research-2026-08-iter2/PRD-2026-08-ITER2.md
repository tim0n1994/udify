## 0. 北极星与一句话

第一轮把引擎闭环搬成产品闭环，第二轮把"合成/关键词/单引擎/预留"的真天花板换成真实闭环。北极星：用一个真实 miu2d demo，说"让第一个 Boss 更难但不碰 Hero"，系统用可选 LLM 解析意图、用 ContentGraph 语义字段精确锁定 Boss 节点、生成字节级稳定的 Patch、用真 Playwright 启动修改后的游戏并断言 Boss 血量变了 Hero 没变。

## 1. 五个编码模块（可独立交付，独占路径）

### 模块 M1 — ContentGraph 语义可观测性（基础设施，最先做）
- 路径独占: udify/models/content_graph.py（扩展 ContentNode.attributes 语义字段约定 + helper）, tests/models/test_semantic_fields.py(新)
- 内容: 定义节点语义属性 schema（is_boss/is_player/enemy_role/hp/max_hp/attack 等），miu2d 适配器感知时填充这些字段，让意图接地与运行时探针有可观测锚点。
- 验收: 节点语义字段有 Pydantic 校验；感知输出 Boss 节点 is_boss=True，Hero is_player=True；新测试全绿，399 回归不破。

### 模块 M2 — 意图真化（LLM 候选 + ReferenceResolver 裁决）
- 路径独占: udify/core/cognition/intent_classifier.py, udify/core/cognition/reference_resolver.py, tests/cognition/test_llm_intent.py(新), tests/cognition/test_reference_resolution.py(新)
- 内容: IntentClassifier 增加可选 LLM 路径（Anthropic tool use 结构化输出，无 key 全降级启发式）；ReferenceResolver 基于 M1 的语义字段做候选生成+硬约束过滤+排序裁决（is_boss=True 排除 Hero）；每 job 2 次 LLM 上限 + cost tracker。
- 验收: "Boss 翻倍不碰 Hero"在合成 ContentGraph 上正确；无 ANTHROPIC_API_KEY 时全降级且 399 测试不触网；有 key 时结构化输出走通（手测，不进 CI 阻塞）。

### 模块 M3 — 真实游戏验证闭环（欠条 B/C 清偿）
- 路径独占: udify/core/validation/runtime_probe.py（Playwright 探针实装）, udify/core/adapters/miu2d.py（目录发现器）, tests/core/validation/test_playwright_probe.py(新)
- 内容: 目录发现器确定真实 web_root；静态文件服务器托管 patched web tree；Playwright 启动→等待加载→读运行时对象→断言；Level 2 探针（启动游戏读状态而非仅读 definition）。
- 验收: 用 JC 提供的合法 miu2d demo，真 Playwright 探针断言修改生效（Boss hp 变、Hero 不变）；无 Playwright 时测试 skip 不伪造通过；欠条 B/C 验收清单逐条留档。

### 模块 M4 — 字节级稳定 Patch（PATCH-SYN-10 + 跨文件）
- 路径独占: udify/core/perception/parsers/ini_parser.py（稳定序列化器）, udify/core/execution/patch_executor.py（就地修改）, tests/core/execution/test_stable_serialization.py(新)
- 内容: ini 字节级稳定序列化（保留注释/空白/键序/未改行不变）；JSON 文件保留键序/缩进/浮点精度；SourceSpan 提升到行级。
- 验收: PATCH-SYN-10 修复——同值修改不再产生 remove/add 噪声行；golden patch 回归测试断言未改行字节不变。

### 模块 M5 — 安全 Agent 循环骨架（LangGraph 编排 + 自研安全边界）
- 路径独占: udify/core/execution/agent_loop.py(新), tests/core/execution/test_agent_loop.py(新)
- 内容: AgentLoop 状态机（plan→gateway→sandbox→audit→human_gate）；LangGraph 编排但 tool node 只调统一 Udify 适配器；R3+ 走 PolicyDecision.requires_human_confirmation；macOS 用 seatbelt/降级沙箱（不承诺 gVisor）；审计链完整性测试。
- 验收: agent 循环在合成任务上跑通 plan→execute→audit；R3 操作触发人工门（测试断言被拦）；审计链篡改则 verify 失败；不旁路 ToolGateway（测试）。

## 2. 集成顺序与契约

M1（语义字段）是 M2/M3 的前置。M2/M3/M4/M5 相互独立可并行编码。集成时 Codex 中心裁决跨模块契约（ContentGraph 字段、ExecutionMode、ProbeSpec）。所有模块在 disposable 测试夹具上验证，不触生产数据。

## 3. 红线（继承 + 新增）

- LLM 只产候选，规则层裁决，无 key 全降级，399 测试不依赖网络。
- 不下版权资源；真 miu2d 用引擎 demo 或 JC 合法拷贝。
- 不承诺 gVisor（macOS 不可用）；沙箱目标 seatbelt/WASM。
- 不改产品入口形态（serve + pnpm dev 不变）。
- 每模块有测试、有类型注解、有验收。

## 4. 分布式编码交付方式

用 orchestrate-sol-browser 开 5 个编码 tab（C1-C5 对应 M1-M5），每 tab 独占路径、附源码包、产出 === FILE: path === 格式完整文件，Codex 用 harvestCode 校验路径归属后 diff/apply/整合/门禁。
