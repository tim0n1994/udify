# Changelog

## 0.1.0a1 — 2026-10-24

This is the first public technical preview of Udify.

- Supports the end-to-end `miu2d` game modding path.
- Generates evidence-backed, reversible CDL patches behind a human approval gate.
- CI passes on Python 3.12 and 3.13.
- 396 tests pass with the enforced 62% coverage floor.
- UdifyBench validation passes.
- Builds a source distribution and wheel for GitHub Release download.

The preview does not include other engine adapters, PyPI publication, production hosting, or a claim of production readiness. See [the release status](docs/RELEASE-STATUS.md) for the verification boundary.
